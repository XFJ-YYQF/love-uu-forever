今天创建了这个仓库，本来是因为写的html文件总是被我搞丢，想扔到Github上保存的，不过突然发现Readme当个小笔记也不错，就写写一些小随笔吧。

这个仓库现在乃至以后都不会有任何AI参与生成，大概都是我的肺腑之言吧，我会尽量想到什么就写什么的，主要是我意识到自己的失忆好像越来越频繁了，有些美好的回忆不该被遗忘的，我想让自己记得更久一些。另外也不太想被uu看到这些话，不过又对被看见抱有一些莫名的期待，所以还是设成public，一切随缘吧。

我不知道自己是怎么爱上你的，可能只是在慢慢的相处中生出的情愫吧。我渐渐感觉自己身上的每个细胞，每一路生物电，每一点神经递质什么的好像都在向我的意识发出喜欢的信号，我从没有过这种感觉，真的好奇怪……

我深知这段感情大概永远都不太可能会有结果，我大概是个无神论者，不过这次，神啊拜托了，让我还能多爱你一会儿吧，哪怕只是再依偎彼此一会儿都好……
